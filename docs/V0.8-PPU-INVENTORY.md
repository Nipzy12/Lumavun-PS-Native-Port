# V0.8 PPU Code Inventory (research prerequisite)

This is a **read-only PowerPC64 PPU static code inventory**, not a PS3 native recompiler, decrypted game extractor, emulator, or playable Gundam Reborn build.

## What the scanner does

The command-line executable `lumavun_ppu_scan.exe` accepts a structurally validated big-endian PPC64 ELF candidate, or a game directory whose PS3_GAME/USRDIR/EBOOT.BIN resolves to such a plaintext ELF.

It streams only executable PT_LOAD segment bytes, categorizes simple branch instruction encodings, and reports:
- Bytes of executable code analyzed and the explicit scan coverage status.
- 32-bit instruction words encountered in executable segments (these are not guaranteed to all be instructions: embedded data may occur).
- Direct branch, conditional branch, branch-and-link, and LR/CTR-indirect branch counts.
- Candidate direct branch-and-link targets within executable segments, a bounded sample of at most 64 addresses.
- Explicit blockers for recompiler, SPU, RSX, CellOS and unverified game identity.

These targets are **not verified function start addresses**. The tool does not construct a complete control-flow graph or disassemble the entire PowerPC instruction set. Function names, game identity, imports, SPU integration and executable version fingerprints remain unverified.

## Memory limits

By default the tool reads at most **16 MiB** of executable segment content, in small 4 KiB chunks. The analysis code has an internal upper bound of 64 MiB. A restricted scan is marked `PARTIAL_SCAN` and the remaining executable code must not be described as analyzed.

No decrypted ELF is created from a SELF container. If the source is a signed/encrypted EBOOT.BIN, the result is `NEEDS_LAWFUL_UNPACKED_ELF` without any execution or decryption.

## How to use

In the launcher: **Import Game File / Folder** then **Analyze PS3 PPU Code (Read Only)**. A report is saved to:

    %LOCALAPPDATA%\LUMAVUN\PSNative\ppu-inventory.json

CLI:

```powershell
.\lumavun_ppu_scan.exe "D:\MyGames\MyPS3Game\EBOOT.ELF" --report "ppu-report.json"
```

CLI exit statuses: 0 complete scan; 3 partial coverage; 4 unsupported/invalid/SELF input; 5 unexpected I/O error; 6 report write failure or refusing to overwrite the source.

## V0.8 Gundam Reborn acceptance gate

To begin work on **actual Gundam Reborn** the project still needs a lawfully obtained, safely accessible game-specific executable from the user's own game copy, correct title and version identification, module/dependency inventory, reliable function discovery, and a per-game native recompilation/runtime prototype. The repository does **not** contain this game or its assets.

Only a game that reaches actual menu/gameplay, graphics, audio, input and saving in the Windows native executable can be called a successful native port. A successful PPU scan is not that.

## Verification

Synthetic ELF64 and SELF fixtures are tested in CTest: direct/conditional/indirect branches, negative and absolute targets, bounded partial coverage, external calls, unsupported input, and truthful reporting. No proprietary PlayStation binaries are used.
