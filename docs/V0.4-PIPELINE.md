# V0.4 Native Porting Pipeline

This stage adds build planning and capability gates, not a playable PS1-PS5 native game translator.

## Components

- Inspector identifies candidate PS1, PS2 or PS3 disc and executable structures.
- Compatibility catalog lives at data/compatibility.tsv with five TAB-separated fields: id, platform, title, state and notes. Every listed title is research-only.
- Backend interface is defined as IRecompilerBackend in src/port_pipeline.hpp. Backend registry is non-executable until a real native code translator is implemented per game.
- Build planning stages are source, compatibility-profile, recompiler, native-runtime, compile, and verification.
- CLI emits JSON for backends, compatibility, plan and build operations.

## Usage on Windows

Run commands from the directory containing lumavun_port.exe and the data directory:

    .\lumavun_port.exe backends
    .\lumavun_port.exe compatibility
    .\lumavun_port.exe plan "D:\MyOwnGame\PS3_GAME" --profile gundam-reborn --report "port-plan.json"
    .\lumavun_port.exe build "D:\MyOwnGame\PS3_GAME" --profile gundam-reborn

Build deliberately returns exit code 4 (BLOCKED), with no game executable generated.
Plan reports obstacles in JSON. Unknown or missing source returns 2 when planning.
Missing or malformed catalog returns 5. Report write failure returns 6.

## Compatibility notes

Gundam Reborn is research-only, and selecting its ID does not verify that an uploaded PS3_GAME folder contains that title. Native recompilation, source version fingerprinting, PPU/SPU/RSX support, graphics, audio and game-specific runtime are NOT implemented.

## Acceptance for a future native port

A game-specific adapter must validate game/version, translate console instructions without launching an emulator, implement required game system services, compile a Windows x64 native target, and pass gameplay, audio, save/load, input and frame-pacing tests. Mere .exe file creation is never sufficient.

No copyrighted assets, firmware or keys are included. AMD A4/Radeon R3/4 GB RAM remains a low-end target for future performance testing, not a guaranteed 30-FPS result.
