# V0.5: PS1 Homebrew Native Recompilation Proof

## Verified scope

This feature demonstrates a genuine, deliberately **limited** static recompilation:
a self-authored PS-X EXE with MIPS-I machine code is translated into C++ host statements,
then compiled as a Windows x64 native executable. There is **no emulator or MIPS opcode
decoder at game runtime**. The code has native compiled control flow and a minimal
console runtime.

The original PS-X EXE uses a custom **demo-only syscall convention**. That convention is
**not the original PlayStation BIOS**. This mini-game is not a port of any commercial
PS1 game, and is not proof that arbitrary commercial titles can be translated.

## Files

- `tools/make_demo_ps1.py`: assembles original MIPS-I instructions, writes a PS-X EXE.
- `tools/ps1_static_recomp.py`: validates PS-X EXE header; translates supported
  addiu/addu/slti/ori/lui/BEQ/BNE/NOP/syscall instructions into C++ and direct gotos.
  Branch delay slots support NOP only. Unsupported opcodes are rejected.
- `tests/test_ps1_recomp.py`: code-generation, native gameplay, bad header,
  bad branch target, and unsupported opcode checks.
- `LumavunPS1MiniPort.exe`: native Windows console mini-game after CI build.

## Windows game steps

Download the build artifact, extract it, and run:

```powershell
.\LumavunPS1MiniPort.exe
```

Press **D** then Enter to move toward the star, **A** then Enter to move left.
Collecting the star at position 4 earns a point, resets the position, and runs
for 10 turns. Press Q to quit early. CI self-test plays a deterministic 10-turn
sequence and checks the outcome:

```text
RESULT score=2 turns=10
```

The packaged artifact also contains `PS1_MINIGAME.EXE` (MIPS code) and
`LumavunPS1MiniPort.cpp` (generated C++ source) so the data flow is inspectable.

## Safety & limitations

The compiler supports only a tiny set of MIPS-I instructions, not PS1 CD-ROM,
GPU, GTE, SPU, kernel interrupts, memory mapping, load delays, game assets,
game-specific rendering or legitimate BIOS syscalls. The proof avoids shipping
copyrighted games or encryption keys.

**The V0.4 `lumavun_port build` command remains blocked for real PS1/PS2/PS3
games.** To lift that restriction requires authenticated per-game native support
and integration of this proof concept into the general compatibility system.

PS3 Gundam Reborn is still not ported.
