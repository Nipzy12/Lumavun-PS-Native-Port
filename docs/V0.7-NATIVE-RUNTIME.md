# V0.7 Native Windows Runtime Prototype

This adds a native Win32 GDI window and keyboard/save host for our self-authored PS1 MIPS-I mini-game. The gameplay code is still generated by static translation of the same PS-X EXE used in V0.5.

## Supported homebrew behavior

- LumavunPS1MiniPortGui.exe is a **genuine native executable** compiled from the translated MIPS game code, using Win32 GDI for graphics. There is no emulator or run-time opcode decoder.
- Keyboard input: A/D or left/right for movement, Space to stay, Escape to quit.
- F5 saves the current position, turn, and score. F9 restores them and resumes on the next step.
- Saved data is a versioned 24-byte file with range and corruption checks under %LOCALAPPDATA%\LUMAVUN\PSNative\homebrew-demo.sav.
- The native window defaults to 960x540, and reads requested width/height from launcher settings when available.
- Basic Windows system sound cue on scoring; **not** a real SPU or audio mixer.
- Event-driven drawing avoids a continuous 60 FPS rendering loop. This is a tiny 2D proof on low-spec hardware, not a benchmark of actual PS3 performance.

## Try on Windows

Extract all build artifacts into one directory, run LumavunPSLauncher.exe, and choose **Play Recompiled PS1 Graphical Demo**. Or launch LumavunPS1MiniPortGui.exe directly.

Blue tile = player. Gold tile = star. Earn points within 10 turns.

## Automated checks

- CTest: native_ps1_gui_self_test runs the windowed compiled target in headless deterministic mode and validates 10 frames, 10 turns, score 2.
- CTest: native_runtime_tests checks save format, checksum corruption, invalid version/ranges and tile layout.
- Existing PS1 recompilation, console game, PS2/PS3 probe, launcher and pipeline tests must still pass.

Manual verification on AMD A4/Radeon R3 is still needed for keyboard, GDI paint, sound and save/load user flows.

## Not a PS3 port

The custom mini-game syscall bridge is **not PlayStation BIOS**. Nothing here recompiles Gundam Reborn or supplies PS2 EE/VU/IOP, PS3 PPU/SPU, RSX graphics, CellOS or commercial-game compatibility. V0.6 real-game function inventory is also incomplete.
