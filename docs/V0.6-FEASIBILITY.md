# V0.6: PS2/PS3 binary feasibility inspection

This is a **read-only analyzer**, not a native recompiler. It reads bounded executable metadata and never runs game code or decrypts a file.

## Supported candidate formats

| Input | Recognition | Limits |
| --- | --- | --- |
| PS2 ELF32 | little-endian ELF32, MIPS e_machine 8 | Candidate only. PS2 identity and actual R5900/VU code are unverified |
| PS3 PPU ELF64 | big-endian ELF64, PowerPC e_machine 21 | Candidate only. No PPU translation, SPU extraction, RSX or CellOS runtime |
| PS3 SPU ELF32 | big-endian ELF32, SPU e_machine 23 | Candidate only. No SPU recompilation |
| EBOOT.BIN SELF | magic bytes 53 43 45 00 | This magic is shared by SCE containers. Might be PS3 or Vita; encryption status unknown. No decrypt/unpack |
| PS3_GAME folder | looks for USRDIR/EBOOT.BIN | Does not authenticate title or version |

The scanner checks ELF class, endianness, type, header table bounds, PT_LOAD file ranges and executable flags. It reads only header data, with at most 512 program headers, and never loads entire game binaries in memory. Fields are untrusted input and structural validation is **not** evidence of safe gameplay or technical compatibility.

## User workflow

1. In `LumavunPSLauncher.exe`, use **Import Game File** or **Import Game Folder**.
2. Click **Analyze PS2/PS3 ELF or SELF**.
3. Read the resulting status; a JSON report is saved to `%LOCALAPPDATA%\LUMAVUN\PSNative\feasibility-report.json`.
4. Alternatively use the CLI:

```powershell
.\lumavun_probe.exe "D:\Games\MyGame\PS3_GAME" --report "feasibility.json"
.\lumavun_probe.exe "D:\Games\MyGame\PS3_GAME\USRDIR\EBOOT.BIN"
.\lumavun_probe.exe "D:\Games\MyPS2Game\GAME.ELF"
```

Exit codes: 0 = valid recognized ELF structure; 3 = SELF container requires handling; 2 = no source/read error; 4 = invalid or unsupported format; 5 = unexpected probe/report processing error; 6 = refused unsafe report output or failed report write.

## Explicit blockers

- PS2: R5900 VU/IOP subsystem integration, GS native renderer, audio and input replacements.
- PS3: PPU instruction recompilation, SPU local storage/jobs, RSX native graphics renderer, CellOS services, audio and input.
- PS3 EBOOT.BIN signed container: ELF content access and version validation are not implemented.
- Gundam Reborn: no game-specific executable was provided or analyzed; no gameplay, function inventory or native port can be claimed.

Tests use **synthetic ELF/SELF fixtures** created in-memory by our own unit tests. No copyrighted assets or keys are included.

## Acceptance for the rest of V0.6

A real authorized game sample (or legally distributable homebrew) must be inspected, with a reproducible title/version fingerprint, static analysis of PPU/SPU or EE/VU function/code coverage, and native runtime gap report. Until that exists, V0.6 is only **partially complete**.
